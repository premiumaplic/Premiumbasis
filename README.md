# SchoolBot — отчёты учебного центра

Telegram-бот на компьютере владельца и приложения (Telegram Mini App) на GitHub Pages.
Учителя заполняют недельные отчёты в приложении «Журнал группы», бот рисует для
каждого ученика карточку-отчёт, учитель сам пересылает её родителю. Владелец видит
весь центр в приложении «Панель центра».

**Версия 2.2.** Бот умеет: роли и доступ (владелец, учитель, **саппорт-учитель**), меню владельца (учителя, группы,
ученики, настройки, баллы экзаменов, тексты), загрузку из Excel, приложение учителя
(главная с «следующим шагом», ученики с подробным профилем, **навыки и темы** —
рейтинг по 6 критериям и выученные/непонятные темы, карта станций, итоги группы,
недельный отчёт, экзамен, тема, подсказки, карточки), панель центра для владельца,
карты станций английского и математики (1–11 класс), напоминания учителям,
карточки-отчёты для родителей с подробной картой пути, подсказки учителю,
зашифрованные бэкапы в закрытый канал, сводку владельцу в конце недели.
Посещаемость по умолчанию выключена (в центре её ведут на другом сайте) —
включается в ⚙️ Настройках. Дальше: пилот с двумя учителями (этап 5).

Посмотреть на выдуманных данных:
приложение учителя https://premiumaplic.github.io/Premiumbasis/app/?demo ·
панель центра https://premiumaplic.github.io/Premiumbasis/owner/?demo

## Установка

### Если ставите впервые
1. Создайте бота у **@BotFather** (`/newbot`) и сохраните токен.
2. Создайте пустую папку, например `D:\SchoolBot` (латиница, без пробелов).
3. Скачайте `scripts/setup.bat` из репозитория (файл на GitHub → «Download raw file»),
   положите в эту папку и запустите. Права администратора не нужны.
   Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» →
   «Выполнить в любом случае».
4. В открывшемся `config.ini` впишите `token`, сохраните (Ctrl+S).
5. Запустите `start.bat`, напишите боту `/myid`, впишите номер в `owner_id`,
   сохраните, закройте окно бота и снова запустите `start.bat`.

### Если уже проходили этап 0
Скачайте **новый** `setup.bat` (как в п. 3) поверх старого и запустите.
Python, `data\` и `config.ini` останутся, добавятся `start.bat` и `update.bat`.
`probe.bat` больше не запускайте одновременно со `start.bat` — у них один токен.

## Каждый день
- Утром запустите `start.bat`. Окно должно оставаться открытым весь день.
- Закрыли окно — бот остановлен. Пока окно открыто, компьютер не уходит в сон
  (настройки электропитания при этом не меняются).
- Если Windows перезагрузилась (например, для обновления) — снова `start.bat`.
- Если бот упал из-за ошибки, окно само перезапустит его через 10 секунд.

## Обновление программы
Закройте окно бота и запустите `update.bat`. Он сделает копию базы
(в `data\backups`), скачает новую версию, обновит базу и сам запустит бота.
Если что-то пойдёт не так — вернёт прежнюю версию программы. База и `config.ini`
не трогаются.

## Панель центра (приложение владельца)
`/start` → под полем ввода кнопка **«📊 Панель центра»** (и «☰ Меню владельца»):
- **Обзор** — сколько отчётов недели заполнено по центру, ученики, группы, учителя,
  отчёты по неделям, распределение оценок (с предупреждением о завышении),
  экзамены в ближайшие 3 недели, кому нужна помощь, кого похвалить (⭐ звёзды недели).
- **Учителя** — у кого сколько групп, заполнено ли, средний уровень; нажатие — группы учителя.
- **Группы** — заполненность отчётов, неделя станции, дни до экзамена, уровень и его
  изменение, подсказки; фильтры «Отстают», «Экзамены», «Подсказки».
- **Станции** — сколько учеников на каждой станции (английский, математика).
- Команды боту: **Напомнить учителям** (тем, у кого есть незаполненные отчёты),
  **Выгрузить отчёты в Excel** (эта и прошлая неделя по всем группам; то же — команда `/export`),
  **Сводка в чат**, **Бэкап сейчас**.
Данные в панели — на момент нажатия кнопки; обновить — «🔄 Обновить» в чате.

## Меню владельца (`/start` или «☰ Меню владельца»)
- **👩‍🏫 Учителя** — добавить по Telegram ID (учитель узнаёт его командой `/myid`),
  выбрать язык (русский/узбекский), отключить.
- **👥 Группы** — создать (название, предмет, учитель, этап, дата старта, дни, время),
  сменить учителя (в том числе на время болезни), этап, расписание, отправить в архив.
- **🎓 Ученики** — добавить, найти, перевести в другую группу (история сохраняется),
  поставить на любую станцию карты, язык карточки, отметка о согласии родителя, архив.
- **📥 Excel** — шаблон для массовой загрузки. Пришлите заполненный файл в чат:
  бот покажет итог («будет добавлено 45 учеников, ошибки в строках…») и применит
  только после кнопки «Применить».
- **⚙️ Настройки** — название центра, день и время напоминаний, время бэкапа,
  пороги подсказок, **посещаемость вкл/выкл** (по умолчанию выключена: раздел скрыт
  у учителей, на карточках и в сводке; прежние отметки сохраняются).
- **🎯 Баллы экзаменов** — проходной и максимальный балл для каждого этапа.

Все изменения владельца записываются в журнал (кто, что, когда).
На каждом шаге ввода есть «⬅️ Назад» (на предыдущий шаг или экран) и «✖️ Отмена» (в меню).
Команды владельца: `/status` — версия и состояние бэкапов, `/log` — последние строки журнала
(для разработчика), `/backup` — бэкап сейчас, `/summary` — сводка.
Учитель видит только свои группы. Посторонний получает «Нет доступа» и свой ID.

## Работа учителя — приложение «Журнал группы»
1. Учитель нажимает в боте `/start`. Под полем ввода появляются кнопки — по одной на
   каждую его группу: «📱 10-А · Английский». (Если кнопок не видно — значок клавиатуры
   справа в строке ввода.)
2. Кнопка открывает **приложение группы** прямо в Telegram. Внизу — меню из пяти вкладок:
   - **🏠 Главная** — группа, неделя станции (8 полосок до экзамена), дни до экзамена,
     серия недель с полными отчётами, кольцо «отчёты недели» и
     **«Следующий шаг»** (заполнить отчёт → отправить карточки → «неделя закрыта»).
     Ниже быстрые действия:
     - **Недельный отчёт** — сначала **настройки отчёта**: неделя (эта / прошлая),
       **как заполнять** — «по ученикам» (каждый отдельно) или «по навыкам» (один навык сразу
       для всего класса, с кнопками «всем: слабо / так себе / хорошо / отлично»),
       **что оценивали на этой неделе** (необязательные навыки можно выключить для всей группы),
       **с чего начать** (как на прошлой неделе / с чистого листа / всем «хорошо»),
       **кого заполнять** (всех / только без отчёта / выбрать). Дальше уровень одним нажатием,
       **★ Звезда недели**, **цель на следующую неделю** (из списка; видна родителю на карточке),
       готовые фразы и комментарий до 80 букв. Черновик сохраняется на телефоне;
     - **🎓 Экзамен** — баллы, «переходит»/«повтор», изменение решения с причиной,
       путь после B2; на станциях без экзамена — решение учителя;
     - **📚 Тема** — юнит из книги или своя тема;
     - **💌 Карточки** — можно выбрать, кому прислать; бот пришлёт картинки в чат;
     - **💡 Подсказки** — с причиной; отмеченные закрываются;
     - **✅ Посещаемость** — только если владелец её включил.
   - **👥 Ученики** — уровень (кольцо), динамика за 8 недель, станция, рейтинг навыков,
     есть ли отчёт; фильтры «Без отчёта», «Внимание», «Звёзды». **Профиль ученика**:
     три главных числа (уровень по отчётам, рейтинг /10 и изменение, сколько тем выучено),
     диаграмма навыков (сейчас и прошлая оценка пунктиром), полосы по каждому критерию,
     кто и когда оценивал, темы «Не понял» и «Выучил», уровень по неделям, отчёт недели
     и цель недели, подсказки, станция и перевод, кнопки «Оценить», «Изменить темы»,
     «Заполнить отчёт».
   - **⬡ Навыки** — отдельное меню «Навыки и темы»:
     - **Ученики**: навыки группы (средний рейтинг, диаграмма, сильнее и слабее всего),
       по каждому ученику — рейтинг /10, мини-диаграмма, сколько тем выучил и не понял,
       когда оценивали. Нажатие открывает **редактор ученика**: шкала 1–10 по каждому
       критерию (нажать или провести пальцем; повторное нажатие снимает оценку; точка —
       прошлая оценка), общий рейтинг и диаграмма меняются сразу; темы «Выучил» /
       «Не понял» — добавить свою или из тем уроков группы, нажатие на тему — перенести
       или убрать; «Предыдущий / Следующий ученик».
     - **Темы**: все темы группы (из формы «Тема урока», юниты книги, темы учеников) —
       сколько выучили и сколько не поняли. Нажатие на тему — у каждого ученика
       «— / Выучил / Не понял», кнопка «Все выучили».
     Критерии языков: Listening, Reading, Writing, Speaking, Grammar, Vocabulary.
     У математики свои 6: устный счёт, вычисления, текстовые задачи, геометрия,
     логика, аккуратность. Оценка — одна в день (повтор в тот же день исправляет её),
     история хранится. Изменения копятся на телефоне (черновик) и уходят боту одной
     кнопкой «Сохранить · N». 3 и больше непонятных темы → подсказка
     «Повторите непонятные темы» (порог — в ⚙️ Настройках).
   - **🗺 Карта** — путь по станциям с разделами (для детей, общий английский, CEFR, IELTS;
     у математики — 1–4, 5–8, 9–11 класс), кто из учеников на какой станции;
     нажатие на станцию — кто там и «перевести всю группу сюда» (можно с пропуском,
     например сразу из Roundup 3 в A1, или назад).
   - **📊 Итоги** — уровень группы и изменение к прошлой неделе, уровень и заполненность
     по неделям, показатели недели по вопросам, кто растёт и кому нужна помощь,
     **Скачать отчёты группы (Excel)** — бот пришлёт файл в чат.
3. Внизу — оранжевая кнопка Telegram «Сохранить». После неё приложение закрывается,
   бот отвечает в чат одной строкой и обновляет кнопки групп.
4. «← Журнал группы» вверху и кнопка Telegram «Назад» возвращают в приложение.
5. В субботу в 18:00 (настраивается) бот напомнит, по каким ученикам нет отчёта.

Почему вход — кнопкой под полем ввода, а не иконкой приложения: по правилам Telegram
только такие приложения могут отправить данные боту без собственного сервера.

Владелец, который сам ведёт группы: добавьте себя учителем (свой Telegram ID),
затем `/start` → «📚 Мои группы (как учитель)».

## Саппорт-учитель
Учитель, который помогает во всех группах. Владелец: 👩‍🏫 Учителя → учитель →
«🛟 Сделать саппорт-учителем» (так же снимается). Саппорт-учитель после `/start` видит
кнопку **«🛟 Все группы»**: выбирает любую группу центра — под полем ввода появляется
кнопка её журнала. В группе он работает как учитель: недельный отчёт, навыки и темы,
экзамен, тема урока, подсказки, карточки, Excel. В приложении сверху написано, чья это
группа. Бот проверяет роль при каждой отправке: если роль снять, чужие группы сразу
закрываются. Напоминания саппорт-учитель получает только по своим группам (если они есть).

Посмотреть приложение на выдуманных данных: https://premiumaplic.github.io/Premiumbasis/app/?demo

## Недельный отчёт: вопросы
Языки: домашнее задание, работа на уроке, новые слова, грамматика, говорение,
аудирование, чтение, письмо, дисциплина. Математика: домашнее задание, работа на уроке,
понимание темы, устный счёт, решение задач, оформление тетради, дисциплина.
Аудирование, чтение, письмо, устный счёт, решение задач и оформление можно пропустить
(«не оценивалось на этой неделе») — на карточку они тогда не попадают. Владелец меняет
тексты, делает вопрос обязательным/необязательным или выключает его: 📚 Тексты → ❓ Вопросы недели.

## Цели на неделю
Учитель выбирает ученику одну цель на следующую неделю («Читать по 15 минут в день»,
«Повторить таблицу умножения»…) — на карточке родителя она в отдельной рамке.
Список (общий, для языков и для математики) меняет владелец: 📚 Тексты → 🎯 Цели на неделю.

## Выгрузка в Excel
Файл: лист «Сводка» (по группам: учеников, заполнено, средний уровень, звёзды) и по листу
на неделю (эта и прошлая): ученик, ответы по каждому вопросу с цветом уровня, средний уровень,
звезда, цель, комментарий; последний лист «Навыки и темы» — последняя оценка по каждому
критерию (с цветом), общий рейтинг, выученные и непонятные темы.
Учитель получает только свою группу, владелец — весь центр.

## Карта математики
11 станций по классам в трёх разделах: **1–4 класс** (счёт, сложение и вычитание,
таблица умножения, действия в столбик), **5–8 класс** (дроби, проценты, уравнения,
корни), **9–11 класс** (функции, тригонометрия, логарифмы, производная).
Переход — по решению учителя (экзаменов и дат нет). Группе математики нужно один раз
выбрать станцию: владелец — «👥 Группы → 🗺 Этап группы», или учитель — вкладка «Карта».
Описания станций меняются в «📚 Тексты → 🗺 Станции карты».

## Карточка для родителя
PNG 1080×1350 на языке ученика (русский или узбекский): имя крупно, группа и неделя,
значок «Звезда недели», **карта пути змейкой** (до 10 станций в два ряда: пройденные
с галочкой, текущая — «сейчас здесь» с кольцом прогресса по неделям, будущие — с месяцем
прогноза), полоска «неделя 6 из 8» с флажком экзамена и числом дней до него, что проходят
на станции, тема, прогноз финиша, посещаемость за месяц (только если включена),
показатели недели в две колонки полосками со стрелками относительно 4 прошлых недель
и мини-график динамики за 6 недель, **цель на следующую неделю**,
одна фраза-вывод, похвала при росте 3 недели подряд, комментарий учителя и статус
«идёт по плану» / «есть риск повтора». Для предметов без карты — курс и тема.

Прогноз считается по календарю экзаменов группы (каждые 2 месяца от начала текущей
станции группы) при условии, что ученик сдаёт с первого раза; каждый повтор сдвигает
линию на 2 месяца. У станций Roundup даты нет — «по решению учителя». CEFR и IELTS —
диапазон 3–5 месяцев. Пока путь после B2 не выбран, обе ветки на карточке серые.
Пропущенные станции (учитель перевёл с пропуском) на карте не показываются.
Группа переходит на следующую станцию после экзамена, если сдала хотя бы половина
всех её учеников; кто на повторе — бот перечислит, владелец решает, куда их перевести.
Карточки хранятся в `data\cards` 8 недель, потом удаляются (их можно нарисовать заново).

**Важно сказать учителям:** формы открываются и сохраняются, даже когда ПК выключен,
но Telegram хранит отправленное только 24 часа. Если бот не включат в течение суток,
данные пропадут.

Повторная отправка той же формы дублей не создаёт. Отметка за тот же день
(или отчёт за ту же неделю) просто исправляется. Пустой комментарий не стирает
прежний.

## Как проверить этап 2
1. Создайте тестовую группу из 15 выдуманных учеников и назначьте её себе
   как учителю (добавьте свой ID в учителя).
2. Заполните недельный отчёт на всю группу — уложиться нужно в 5 минут.
3. Отправьте одну и ту же форму два раза (например, нажмите «Сохранить»,
   затем снова откройте и сохраните без изменений) — в базе не появятся дубли.
4. Переведите ученика в другую группу и, не обновляя кнопки, отправьте старую
   форму — бот скажет, что для этого ученика не сохранено.

## Дизайн и анимации
Дизайн собран по общепринятым исследованиям и руководствам, а не «на глаз»:
- **Контраст** — текст не ниже 4.5:1 (WCAG 2.2, уровень AA): кнопки тёмно-оранжевые
  (белый текст 4.7:1), серый текст темнее, чем был. Тёмная тема — по теме Telegram.
- **Размер касания** — кнопки и строки не меньше 44–48 px (Apple Human Interface
  Guidelines, Material Design 3); главное действие — внизу, под большим пальцем.
- **Цвет — не единственный признак** (WCAG 1.4.1): у «выучил / не понял», уровней и
  подсказок всегда есть текст или значок.
- **Узнавание вместо припоминания** (эвристики Нильсена): темы уроков группы — готовыми
  подсказками, прошлая оценка — точкой на шкале.
- **Движение** — по Material Design 3: появление 300–400 мс с «замедлением в конце»,
  уход 150–200 мс с «ускорением»; анимации интерфейса в пределах 100–500 мс
  (Nielsen Norman Group). Переходы между экранами — через View Transitions API:
  вглубь экран въезжает справа, назад — слева, вкладки сменяются мягким «перетеканием»;
  аватар и имя ученика «перелетают» из списка в профиль. Бегунок нижнего меню и
  переключателей скользит, диаграмма навыков «раскрывается» из центра, полосы
  заполняются, числа плавно меняются, шкала 1–10 заполняется волной, отметки слегка
  «подпрыгивают», нижняя шторка закрывается свайпом вниз, шапка получает тень при прокрутке.
  На старых телефонах без View Transitions экраны просто плавно въезжают.
- В телефоне включено «Уменьшить движение» — все анимации выключаются.

## Подсказки учителю (приложение → «💡 Подсказки»)
Простые правила, пороги — в ⚙️ Настройках (это стартовые предположения:
через месяц работы их стоит подстроить):

| Условие | Подсказка |
|---|---|
| 2 пропуска подряд или 3 за месяц (уважительные не считаются; только если посещаемость включена) | «Свяжитесь с родителем» |
| 3 опоздания за 2 недели (только если посещаемость включена) | «Обсудите опоздания» |
| Домашка «не сделано» или «частично» 2 недели подряд | «Домашка проседает» |
| Показатель упал на 2 ступени от среднего за 4 недели | «Резкий спад: …» |
| За 3 недели до экзамена средний уровень ниже проходного | «Риск не сдать экзамен» |
| Рост 3 недели подряд | «Похвалите» (и строка похвалы на карточке) |
| 3 и больше темы «Не понял» в меню «Навыки и темы» | «Повторите непонятные темы» |
| Отчёт не заполнен к концу недели | напоминание от бота |

Под каждой подсказкой — почему она появилась («пропуски: 12 и 14 ноября»), у каждой
кнопка «Закрыть». Закрытая подсказка не повторяется, пока условие не исчезнет;
если условие исчезло само (например, отметку исправили) — подсказка закрывается сама.
После сохранения формы бот пишет, если появились новые подсказки.

## Бэкапы
Каждый день в 21:30 (настраивается), по команде `/backup` (или меню → 💾 Бэкап сейчас)
и перед каждым обновлением бот делает согласованную копию базы, шифрует её
(zip, AES-256, пароль из `config.ini`) и отправляет в ваш закрытый канал.
На ПК хранятся 7 последних копий (`data\backups`). Если ПК был выключен в 21:30,
бэкап сделается сразу после следующего запуска. Файл больше 49 МБ уходит частями
(.001, .002…), бот предупредит. Пароль нигде не печатается.

**Настройка один раз:**
1. В Telegram создайте **канал** (не группу!), тип «Частный» — например «Бэкапы центра».
2. Пока работает бот, добавьте его в канал **администратором** с правом публиковать
   сообщения (канал → Управление → Администраторы → Добавить → найдите бота).
   Бот сам запомнит канал (запишет его ID в `config.ini`) и сообщит вам об этом.
   Если сообщения нет — перешлите боту любое сообщение из канала (без скрытия
   отправителя), бот сделает то же самое. Проверка: команда `/status`.
4. В `config.ini` в разделе `[backup]` впишите длинный пароль: `password = …`
   **Запишите пароль на бумаге** — без него бэкап не открыть.
5. Перезапустите бота. При запуске он пишет «Бот запущен (версия …)», проверяет,
   что может публиковать в канал, и напишет вам, если что-то не так.

**Восстановление:** закройте окно бота, скачайте файл бэкапа из канала
(если частей несколько — все в одну папку), запустите `restore.bat`, перетащите
файл в окно, введите пароль, подтвердите. Текущая база сначала сохранится
в `data\backups` с пометкой даты, и только потом заменится.
Проверить бэкап можно и в другой папке: поставьте `setup.bat` в `D:\SchoolBotTest`
и восстановите туда.

## Сводка владельцу
В день напоминаний в 20:00 (настраивается) или по кнопке «📊 Сводка»:
сколько отчётов заполнено у каждого учителя и по каким ученикам их нет,
как распределены оценки 0–3 у каждого учителя (если почти все ответы «3» —
предупреждение о возможном завышении), пропуски и опоздания за неделю,
число открытых подсказок.

## Тексты (меню → 📚 Тексты)
- **Юниты книги** — список тем для этапа (каждый юнит с новой строки); учитель
  выбирает юнит в форме «Тема».
- **Вопросы недели** — правка вопросов и вариантов на русском и узбекском,
  отметка «узбекский проверен».
- **Готовые фразы** — фразы для комментария, «русский | узбекский».

## Как проверить этап 4
1. Настройте канал и пароль (см. «Бэкапы»), нажмите «💾 Бэкап сейчас» —
   файл появился в канале.
2. Скачайте его, поставьте программу в другую папку (`setup.bat`), запустите там
   `restore.bat` — база восстановится и откроется (бот покажет ваши группы).
3. Отметьте ученику 2 пропуска подряд — у учителя появится подсказка
   «Свяжитесь с родителем» с датами.

## Как проверить этап 3
1. Меню → 🎯 Баллы экзаменов → задайте баллы для Курс A1 (например, 60 и 100).
2. Учитель: 🎓 Экзамен → одному ученику балл ниже проходного → «повтор».
   На карточке этого ученика прогноз финиша сдвинется на 2 месяца.
3. 📤 Карточки для родителей → карточки приходят на русском и узбекском
   (по языку ученика), каждая рисуется меньше чем за 2 секунды.
4. У группы на Roundup на карточке вместо даты — «по решению учителя».

## Как проверить этап 1
1. Установка прошла до конца на обычной учётной записи Windows без прав администратора.
2. `check.bat` пишет «Вне папки ничего не найдено».
3. С чужого Telegram-аккаунта: `/start` → «Нет доступа» и ID.
4. Меню → 📥 Excel → шаблон → заполните 3 группы по 15 учеников (выдуманных) →
   пришлите файл → бот показывает итог → «Применить» → группы и ученики появились.
5. Добавьте учителя, назначьте ему группу — учитель на `/start` видит только её.

## Этап 0 (проверки) — что осталось
Проверено на Android и Telegram Desktop. Не проверены iPhone и отправка формы при
выключенном боте — это можно сделать позже тестовым ботом `probe.bat`
(сначала закройте окно `start.bat`): кнопки «🧪 Форма» и «📊 Итоги».

**Решение по итогам этапа 0:** данные формы передаются в ссылке после `#` —
так они не уходят на серверы GitHub. Ссылка формы для группы из 20 учеников —
около 1200 символов (проверено). Если ссылка получится длиннее порога
(настройка «Длина ссылки формы»), форма делится на части.

## Что программа пишет вне своей папки
По замыслу — ничего. Python, библиотеки, временные файлы, настройки matplotlib —
всё внутри папки. `check.bat` проверяет обычные места, куда Python и pip пишут
по умолчанию, и сохраняет отчёт в `data\check_outside.txt`.

Не от программы, но может появиться при обычной работе Windows и Telegram:
- если открывать формы в Telegram Desktop, Telegram хранит данные своих
  встроенных страниц в собственной папке — так же, как для любых мини-приложений;
- Блокнот запоминает свои настройки (размер окна и т.п.);
- Windows помечает скачанный `setup.bat` как файл из интернета.

Ярлык в «Автозагрузку» не создаётся. Если захотите — скажите разработчику.

## Известные риски и ограничения
- **База на диске не зашифрована.** Шифрование диска — это настройка Windows,
  а её трогать нельзя. Защита: доступ к ПК, бэкапы зашифрованы паролем (этап 4).
- **Отправленные формы Telegram хранит 24 часа.** Если бот был выключен дольше,
  данные теряются. Об этом нужно сказать учителям.
- **Состояние диалогов в памяти.** Если бот перезапустился посреди ввода
  (например, создания группы), начните заново с `/start`.
- **Узбекские тексты — черновик**, их нужно проверить владельцу. Готовые фразы
  для комментария — тоже черновик (таблица `phrases`, позже — правка из меню).
