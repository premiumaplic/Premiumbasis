# SchoolBot — отчёты учебного центра

Telegram-бот на компьютере владельца и формы для учителей на GitHub Pages.
Учителя отмечают посещаемость и заполняют недельные отчёты, бот рисует для
каждого ученика карточку-отчёт, учитель сам пересылает её родителю.

**Сейчас готов только этап 0: проверка, на которой держится вся схема.**
Основного бота ещё нет: есть тестовый бот с одной пробной формой.

---

## Этап 0. Как провести проверку

Понадобится примерно 30–40 минут. Нужен ПК, ваш телефон и, если получится,
телефон другой системы (Android или iPhone) у кого-то из учителей.

### Шаг 1. Создать бота в Telegram

1. Откройте в Telegram **@BotFather**, отправьте `/newbot`.
2. Придумайте имя (например «Отчёты центра») и адрес бота (должен кончаться на `bot`).
3. BotFather пришлёт **токен** — длинную строку вида `123456789:AA...`.
   Это пароль от бота: никому его не пересылайте.

### Шаг 2. Включить GitHub Pages (адрес для форм)

1. Откройте репозиторий на GitHub → **Settings** → слева **Pages**.
2. В «Build and deployment» выберите **Deploy from a branch**.
3. Branch: основная ветка репозитория, папка: **/docs** → **Save**.
4. Через 1–2 минуты откройте `https://premiumaplic.github.io/Premiumbasis/` —
   должна открыться страница «Формы учебного центра».

Это бесплатно, потому что репозиторий публичный. В нём только код:
никаких имён учеников, токенов и паролей.

### Шаг 3. Установка на ПК

1. Создайте пустую папку, например `D:\SchoolBot`
   (в пути — только латинские буквы, без пробелов).
2. Скачайте файл `scripts/setup.bat` из репозитория (откройте файл на GitHub →
   кнопка «Download raw file») и положите его в эту папку.
3. Запустите `setup.bat` двойным щелчком. Если Windows покажет «Система Windows
   защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
   Права администратора не нужны.
4. Установка скачает программу и переносной Python (около 300 МБ),
   проверит себя и откроет `config.ini` в Блокноте.
5. Впишите в `config.ini` токен бота (строка `token =`) и сохраните (Ctrl+S).

### Шаг 4. Запустить тестового бота

1. Запустите `probe.bat`. Окно должно оставаться открытым.
2. Напишите своему боту в Telegram `/myid` — он пришлёт ваш Telegram ID.
3. Впишите этот номер в `config.ini` в строку `owner_id =`, сохраните,
   закройте окно бота и снова запустите `probe.bat`.
4. Если помогает учитель — пусть тоже напишет боту `/myid`, а вы впишите его номер
   в строку `testers =`.

### Шаг 5. Проверки в Telegram

Нажмите в чате с ботом `/start` — внизу появятся кнопки.

| Что сделать | Что проверяем |
|---|---|
| **🧪 Форма (#)** → выбрать «Недельный отчёт на 20 учеников» → **Отправить** | отправка формы и размер отправки |
| **🧪 Форма (?)** → «Короткая проверка» → **Отправить** | куда класть данные в ссылке |
| **🧪 Форма (#)** → «Ровно 4096 байт» → **Отправить** | предел Telegram |
| **🧪 Форма (#)** → «4097 байт» → **Отправить** — форма должна сказать, что Telegram не дал отправить | предел Telegram |
| **📏 Длина ссылки (#)**, потом каждая кнопка «📏 …» → **Отправить**. Потом то же для **(?)** | какую длину ссылки выдерживает Telegram |
| Закройте окно бота. На телефоне откройте **🧪 Форма (#)** → **Отправить**. Подождите 5 минут, запустите `probe.bat` | приходят ли данные, отправленные при выключенном боте |

Повторите первые две строки таблицы **на Android, на iPhone и в Telegram Desktop
на ПК** (сколько получится). Если при открытии формы Telegram показывает
какое-то предупреждение — сфотографируйте его.

### Шаг 6. Отправить результат разработчику

1. Запустите `check.bat` — он проверит, что вне папки ничего не появилось.
2. Нажмите в боте **📊 Итоги** и перешлите это сообщение разработчику.

## Что программа пишет вне своей папки

По замыслу — ничего. Python, библиотеки, временные файлы, настройки matplotlib —
всё внутри папки. `check.bat` проверяет обычные места, куда Python и pip пишут
по умолчанию, и сохраняет отчёт в `data\check_outside.txt`.

Не от программы, но может появиться при обычной работе Windows и Telegram:
- если открывать формы в Telegram Desktop, Telegram хранит данные своих
  встроенных страниц в собственной папке — так же, как для любых мини-приложений;
- Блокнот запоминает свои настройки (размер окна и т.п.);
- Windows помечает скачанный `setup.bat` как файл из интернета.

## Известные риски и ограничения

- **База на диске не зашифрована.** Шифрование диска — это настройка Windows,
  а её трогать нельзя. Защита: доступ к ПК, бэкапы зашифрованы паролем.
- **Отправленные формы Telegram хранит 24 часа.** Если бот был выключен дольше,
  данные теряются. Об этом нужно сказать учителям.
- **Где передавать данные в ссылке формы (после `#` или после `?`)** — решается
  по итогам этапа 0. Данные после `#` не уходят на серверы GitHub, после `?` —
  уходят в адресе запроса (только имя, первая буква фамилии и внутренние номера).

## Устройство на ПК

```
D:\SchoolBot\
  app\         копия программы (заменяется при обновлении)
  python\      переносной Python и библиотеки
  data\        база, журналы, карточки, бэкапы (только на этом ПК)
  config.ini   токен, ID владельца, ID канала, пароль бэкапа
  setup.bat  probe.bat  check.bat
```

## Для разработчика

```
bot/          код бота (сейчас: тестовый бот этапа 0 и общие модули)
docs/         формы Mini App (GitHub Pages, папка /docs)
assets/       шрифты, шаблон Excel (позже)
scripts/      setup.bat, probe.bat, check.bat, проверка на секреты
tests/        автотесты на выдуманных данных
```

- Тесты: `pip install -r requirements-dev.txt && python -m pytest tests`
- Проверка на секреты перед коммитом:
  `cp scripts/pre-commit .git/hooks/pre-commit`
  (то же самое запускается в GitHub Actions).
- `.bat` и `.ps1` хранятся с переводами строк Windows (CRLF), `.ps1` — в UTF-8 с BOM,
  иначе Windows PowerShell 5.1 исказит русский текст.
